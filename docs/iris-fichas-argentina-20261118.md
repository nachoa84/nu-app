# Fichas técnicas de Argentina para Iris

Preparado el 18/11/2026 para revisión en preview.

Se verificaron 105 PDF enlazados desde las dos bibliotecas oficiales de Nu Skin Argentina. Se seleccionaron 81 fichas de información de producto, agrupadas por línea, con acceso individual mediante «ficha técnica [producto]». Los enlaces seleccionados respondieron HTTP 200 y su contenido comienza con la firma PDF. El inventario JSON conserva origen, tamaño y SHA-256.

Fuentes:
- https://www.nuskin.com/content/nuskin/es_AR/office/Office-Library/nuskin_products.html
- https://www.nuskin.com/content/nuskin/es_AR/office/Office-Library/pharmanex_products.html

La biblioteca oficial conserva documentos de productos y presentaciones anteriores; esta revisión no acredita disponibilidad comercial ni que cada ficha sea la última edición. No se considera completada la cobertura de todos los productos del catálogo actual. También se revisaron los enlaces PDF del HTML de 148 páginas de producto del listado legado, sin encontrar PDF adicionales enlazados allí.

Se excluyeron materiales complementarios, duplicados y algunas versiones alternativas. Se corrigió el título de Pumps Vitamin C + Collagen (la biblioteca lo rotula como Bakuchiol). Se excluyó el enlace Intensive Eye Complex: contiene una rutina general de piel, no esa ficha.

LifePak Elements y Nu Biome conservan acceso a los archivos que ya existían en Iris, separados como material preexistente pendiente de verificar para Argentina. El inventario enumera otros productos cuya ficha argentina no se localizó en las fuentes revisadas, entre ellos Prysm iO y las nuevas fórmulas de cuidado facial. No se sustituyeron con fichas de otro mercado.

La implementación añade «Fichas técnicas» en Productos y asesoramiento, búsquedas individuales y enlaces directos a los PDF oficiales. No descarga los PDF para uso sin conexión. La rama parte de 9109097 (Estrategia Europa) y mantiene ese trabajo.

Validación: pruebas de resolución de las 81 fichas, búsquedas habituales, integridad del inventario y regresión de la guía miembro a afiliado.
